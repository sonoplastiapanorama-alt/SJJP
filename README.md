# Website Oficial - IASD Jardim Panorama

O website da **Igreja Adventista do Sétimo Dia do Jardim Panorama** é uma plataforma institucional desenvolvida para centralizar a comunicação da igreja local com seus membros e servir como uma porta de entrada digital para a comunidade de Ipatinga/MG.

---

O objetivo principal deste projeto é cumprir a missão da igreja através da tecnologia, facilitando o acesso à informação e encurtando a distância entre as pessoas e a comunidade de fé.
